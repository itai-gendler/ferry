# Ferry 1.0.3

> [English](1.0.3.md) | 简体中文

Ferry 1.0.3 是 Ferry Web 应用的一次小更新。你的消息、文件、设备和密码都不受影响。

## 我该下载哪个文件？

- **新安装：下载 `ferry-1.0.3-docker-compose.tar.gz`。** 它不是程序本身，而是 Docker Compose 需要的三个文件：`compose.yaml`、`.env.example` 和备份脚本。之后由 Compose 拉取程序本体，也就是公开镜像 `ghcr.io/max1874/ferry:1.0.3`，支持 `linux/amd64` 和 `linux/arm64`。
- **已经在运行 1.0.0、1.0.1 或 1.0.2？** 不需要下载，见[升级](#升级)。
- **Source code (zip / tar.gz)** 是 GitHub 自动附带给开发者的源码。运行 Ferry 不需要它。

## 改动

- **加载中的图片看得出在加载。** 以前图片还在传输时，Web 应用显示的是浏览器的破图图标和文件名，看起来像图片坏了。现在图片出来之前显示一个转圈。
- **图片不会再一直卡在加载中。** 以前图片加载时如果连接断开或重新连接，图片可能一直是灰框，要刷新页面才出来。现在连接恢复后会自己重新加载。如果 Server 60 秒都没有回应，图片会变成文件卡片，点一下可以下载。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.3/ferry-1.0.3-docker-compose.tar.gz
tar -xzf ferry-1.0.3-docker-compose.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改成这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

README 里有完整步骤、其他部署方式和排错说明。

## 升级

在你的 `ferry` 目录里，先备份：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.3.tar.gz
```

把 `.env` 里的 `FERRY_IMAGE` 改成 `ghcr.io/max1874/ferry:1.0.3`，然后运行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

## 限制

- Ferry 为可信私有网络提供明文 HTTP。请不要把它暴露到公网；支持在私有网络内使用你自己的 TLS 反向代理。
- Chrome 和其他 Chromium 内核浏览器会拦截来自明文 `http://` 地址的下载。可以在浏览器的下载列表里选择保留，或在 Ferry 地址的网站设置里允许「不安全内容」。
