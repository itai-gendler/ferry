# Ferry 1.0.2

> [English](1.0.2.md) | 简体中文

Ferry 1.0.2 是 Ferry Server 和 Web 应用的一次小更新。你的消息、文件、设备和密码都不受影响。

## 我该下载哪个文件？

- **新安装：下载 `ferry-1.0.2-docker-compose.tar.gz`。** 它不是程序本身，而是 Docker Compose 需要的三个文件：`compose.yaml`、`.env.example` 和备份脚本。之后由 Compose 拉取程序本体，也就是公开镜像 `ghcr.io/max1874/ferry:1.0.2`，支持 `linux/amd64` 和 `linux/arm64`。
- **已经在运行 1.0.0 或 1.0.1？** 不需要下载，见[升级](#升级)。
- **Source code (zip / tar.gz)** 是 GitHub 自动附带给开发者的源码。运行 Ferry 不需要它。

## 改动

- **Web 下载立即开始。** 以前在 Web 应用里点文件，页面要先把整个文件取回来，浏览器才开始保存；文件大或网络慢时，看起来像什么都没发生。现在由浏览器自己的下载器保存文件，照常显示进度。
- **安卓 App 的内置浏览器能保存文件了。** 有些 App 的内置浏览器保存不了旧的页面内下载，会提示「没有应用可执行此操作」。现在下载是你 Ferry 服务器上的一个普通链接，这类浏览器可以把它交给系统浏览器。
- **链接怎么起作用。** Web 应用向 Server 要一个指向某个文件的链接。这个链接五分钟内无需登录即可使用，只能下载这一个文件；Server 重启或申请它的设备被移除后即失效。原生 App 的下载方式不变。
- **许可证是 MIT。** 镜像标签现在写的是 MIT，与仓库一致。

## 安装

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.2/ferry-1.0.2-docker-compose.tar.gz
tar -xzf ferry-1.0.2-docker-compose.tar.gz
cd ferry
cp .env.example .env    # 把 FERRY_HOST_IP 改成这台服务器的局域网 IP
docker compose up -d
docker compose logs ferry
```

README 里有完整步骤、其他部署方式和排错说明。

## 升级

在你的 `ferry` 目录里，先备份：

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.2.tar.gz
```

把 `.env` 里的 `FERRY_IMAGE` 改成 `ghcr.io/max1874/ferry:1.0.2`，然后运行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

## 限制

- Ferry 为可信私有网络提供明文 HTTP。请不要把它暴露到公网；支持在私有网络内使用你自己的 TLS 反向代理。
- Chrome 和其他 Chromium 内核浏览器会拦截来自明文 `http://` 地址的下载。可以在浏览器的下载列表里选择保留，或在 Ferry 地址的网站设置里允许「不安全内容」。
