# Ferry 1.0.3

> English | [简体中文](1.0.3.zh-Hans.md)

Ferry 1.0.3 is a small update to the Ferry Web app. Your messages, files, devices and password are not touched.

## Which file do I need?

- **New install: download `ferry-1.0.3-docker-compose.tar.gz`.** It is not the program itself but the three files Docker Compose needs: `compose.yaml`, `.env.example` and the backup script. Compose then pulls the program, the public image `ghcr.io/max1874/ferry:1.0.3`, for `linux/amd64` or `linux/arm64`.
- **Already running 1.0.0, 1.0.1 or 1.0.2?** You do not need the download; see [Upgrade](#upgrade).
- **Source code (zip / tar.gz)** is added by GitHub for developers. You do not need it to run Ferry.

## What's changed

- **Loading images look like they are loading.** While an image was still on its way, the Web app showed the browser's broken-image icon and the file name, so it looked like the image had failed. It now shows a spinner until the image appears.
- **Images no longer stay stuck loading.** If the connection dropped or reconnected while an image was loading, the image could stay a grey box until the page was reloaded. It now loads again by itself once the connection is back. If the Server gives no answer for 60 seconds, the image turns into a file card you can tap to download.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.3/ferry-1.0.3-docker-compose.tar.gz
tar -xzf ferry-1.0.3-docker-compose.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The README covers every step, other deployment paths and troubleshooting.

## Upgrade

In your `ferry` directory, back up first:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.3.tar.gz
```

Change `FERRY_IMAGE` in `.env` to `ghcr.io/max1874/ferry:1.0.3`, then:

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

## Limits

- Ferry serves plain HTTP for a trusted private network. Keep it off the public Internet; a TLS reverse proxy of your own inside the private network is supported.
- Chrome and other Chromium browsers block downloads from a plain `http://` address. Keep the file from the browser's download list, or allow "Insecure content" in the site settings for your Ferry address.
