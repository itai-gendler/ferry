# Ferry 1.0.2

> English | [简体中文](1.0.2.zh-Hans.md)

Ferry 1.0.2 is a small update to the Ferry Server and Web app. Your messages, files, devices and password are not touched.

## Which file do I need?

- **New install: download `ferry-1.0.2-docker-compose.tar.gz`.** It is not the program itself but the three files Docker Compose needs: `compose.yaml`, `.env.example` and the backup script. Compose then pulls the program, the public image `ghcr.io/max1874/ferry:1.0.2`, for `linux/amd64` or `linux/arm64`.
- **Already running 1.0.0 or 1.0.1?** You do not need the download; see [Upgrade](#upgrade).
- **Source code (zip / tar.gz)** is added by GitHub for developers. You do not need it to run Ferry.

## What's changed

- **Web downloads start at once.** Clicking a file in the Web app used to fetch the whole file into the page before the browser saved anything, so a large file or a slow connection looked like nothing had happened. The browser's own downloader now saves the file, with its usual progress.
- **Android in-app browsers can save files.** Some apps' built-in browsers could not save the old in-page download and showed "No app can perform this action". The download is now an ordinary link on your Ferry server, which such a browser can hand to the system browser.
- **How the link works.** The Web app asks the Server for a link to one file. The link works for five minutes without signing in, only for that file, and stops working when the Server restarts or the device that asked for it is removed. The native apps download as before.
- **License is MIT.** The image label now says MIT, matching the repository.

## Install

```bash
curl -fLO https://github.com/max1874/ferry/releases/download/v1.0.2/ferry-1.0.2-docker-compose.tar.gz
tar -xzf ferry-1.0.2-docker-compose.tar.gz
cd ferry
cp .env.example .env    # set FERRY_HOST_IP to this server's LAN IP
docker compose up -d
docker compose logs ferry
```

The README covers every step, other deployment paths and troubleshooting.

## Upgrade

In your `ferry` directory, back up first:

```bash
scripts/ferry-data.sh backup ../ferry-backup-before-1.0.2.tar.gz
```

Change `FERRY_IMAGE` in `.env` to `ghcr.io/max1874/ferry:1.0.2`, then:

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 ferry
```

## Limits

- Ferry serves plain HTTP for a trusted private network. Keep it off the public Internet; a TLS reverse proxy of your own inside the private network is supported.
- Chrome and other Chromium browsers block downloads from a plain `http://` address. Keep the file from the browser's download list, or allow "Insecure content" in the site settings for your Ferry address.
